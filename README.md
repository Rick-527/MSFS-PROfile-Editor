# MSFS PROfile Editor

A Windows desktop utility for Microsoft Flight Simulator that makes it easy to manage, maintain, and protect important simulator configuration files.

MSFS Profile Editor allows you to quickly switch profiles, back up critical configuration files, and perform common maintenance tasks without manually searching through your simulator folders.

Designed with simplicity and reliability in mind, it supports both the Steam and Microsoft Store editions of Microsoft Flight Simulator.

---

## Features

### Profile Management

- Create and manage simulator profiles
- Quickly apply a selected profile
- Automatically detect simulator installation
- Supports Steam and Microsoft Store editions
- Launch MSFS from with the program

### Maintenance Tools

- Backup **EXE.xml**
- Delete **RollingCache.ccc**
- Backup **SceneryIndexes**
- Clear SceneryIndexes after backup
- Manage camera settings via Cameras.cfg

### Backup Management

- Automatic timestamped backups
- Never overwrites previous backups
- Remembers your preferred backup location
- Simple restore process

### Modern Interface

- Clean Windows interface
- Dark theme
- Status updates during operations
- Helpful error messages
- Safe confirmation dialogs before destructive actions

---

## Why Use MSFS Profile Editor?

Instead of manually browsing through hidden Windows folders and copying simulator files yourself, MSFS Profile Editor provides a simple interface for common maintenance operations.

Whether you're troubleshooting the simulator, experimenting with scenery, or simply protecting important configuration files before making changes, MSFS Profile Editor helps automate those tasks safely.

## Installation

1. Download the latest release.
2. Extract the ZIP file.
3. Run **MSFSProfileEditor.exe**.
4. No installation required.
