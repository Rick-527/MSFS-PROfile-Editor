
MSFS PROfile Editor

Purpose of the program
I found I was having to manually copy and replace filenames whenever I wanted to do certain type of flights, such as bush, local VFR, or IFR. Depending on the type of flight, I would have to swap out the UserCfg.opt file and use different graphic settings for each mode. This was tiresome and tedious, especially when I would delete or overwrite the wrong file.

This program allows you to quickly change the UserCfg.opt file contents found in MSFS2024 to use whichever graphic profile you have saved.

****************************
INSTALLATION
****************************
Simply drag the contents of the zip folder onto your hard drive and run the file MSFS PROfile Editor.exe

****************************
HOW TO USE THE PROGRAM
****************************
Your flight simulator cannot be running. This program has to run prior to starting your sim.

First, you select the UserCfg.opt file in the File 1 group box normally located in the following locations:

MS Store / Xbox App Version:
C:\Users\YOUR_USERNAME\AppData\Local\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache

Steam Version:C:\Users\YOUR_USERNAME\AppData\Roaming\Microsoft Flight Simulator 2024

Next, you select File 2, the profile text file that you have saved in a folder on your hard drive. I named my folder MSFS User Profiles. Here I keep all my profiles. Once both files are selected you then click the 'OVERWRITE FILE 1 CONTENTS' button and the program does the work in the back end. I select the one I want to use and the program does all the updating for you.

The program will remember the last directory you were in prior to closing the program. It also reverts back to the UserCfg.opt file each time the program opens, or whichever filename  is populated in File 1 group box at the time.

You will be prompted to confirm your choice and create a backup of the file selected in the File 1 group box.
The backup file will be saved in the original file location as [originalfilename].bak.

****************************
HOW TO CREATE PROFILES
****************************
Profiles are simply copies of your UserCfg.opt file. The simplest way to set this up initially is to open your simulator and set all the graphic settings you want for the current profile. You can also open the file with Notepad and make the changes there, without opening the sim.

This is done by opening UserCfg.opt under the File 1 group box. Once the file is selected, simply click the 'Save as...' button and navigate to the folder where you want to save your profile. Name this file so it's meaningful to you. That is to say, if I had all my graphic settings set to Ultra, then I would simply call this file UltraSettings.opt.

Again, it's best to keep these new files stored in a folder outside of your simulator. Once the file is saved it's always available to use.
You can name the file whatever you like. All the program does is copy the contents of the profile file and overwrite the existing UserCfg.opt file. It's important not to change the format of the .opt file, but you can change the values.
